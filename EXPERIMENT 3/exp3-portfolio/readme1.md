# Portfolio SPA using React Router

## 📌 Aim

To create a portfolio-based Single Page Application (SPA) using React Router that demonstrates client-side routing between multiple components without reloading the page.

---

## 🛠️ Software Requirements

- Node.js
- React
- React Router DOM
- Web Browser
- Code Editor (VS Code)

---

## 📖 Description

This project is a **Portfolio Single Page Application** built using **React and React Router**.  
The application uses client-side routing to navigate between different sections such as **Profile** and **Dashboard** while maintaining SPA behavior.

---

## 🧩 Features

- Profile photo displayed on the main screen
- Bio (Aim), Projects, and Achievements section
- Navigation buttons for Profile and Dashboard
- Profile section shows personal details and projects
- Dashboard section shows skills
- Navigation without page reload
- Responsive and centered UI layout

---

## 🗂️ Application Routes

| Route        | Component | Description                  |
| ------------ | --------- | ---------------------------- |
| `/`          | Home      | Main portfolio view          |
| `/profile`   | Profile   | Profile details and projects |
| `/dashboard` | Dashboard | Skills section               |
