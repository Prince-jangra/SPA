# Screenshots Guide

To add screenshots to your Urbanova project:

## Steps to Add Images:

1. **Take Screenshots** of your application:
   - Login page
   - Dashboard overview
   - Sidebar navigation
   - Profile & settings page

2. **Save Images** in this directory with these names:
   - `login.png` - Login page screenshot
   - `dashboard.png` - Main dashboard view
   - `sidebar.png` - Sidebar navigation panel
   - `settings.png` - Profile & settings page

3. **Image Specifications**:
   - Format: PNG, JPG, or WEBP
   - Width: 1200-1400px recommended
   - Height: 800-1000px recommended
   - File size: < 500KB each

4. **Upload Images**:
   - Copy your screenshot files to this folder
   - Push to GitHub: `git add public/screenshots/` and `git commit -m "Add screenshots"`
   - Images will automatically appear in README.md

## Example:

If you have a screenshot file, save it as:

```
public/screenshots/login.png
public/screenshots/dashboard.png
public/screenshots/sidebar.png
public/screenshots/settings.png
```

The README.md will automatically reference these files!
